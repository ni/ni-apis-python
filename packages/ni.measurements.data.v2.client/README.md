# About

`ni.measurements.data.v2.client` is a Python package that provides a gRPC
client for the NI Data Store Service, version 2.

NI created and supports this package.

## Operating System Support

`ni.measurements.data.v2.client` supports Windows and POSIX operating systems.

## Python Version Support

`ni.measurements.data.v2.client` supports CPython 3.10+.

## Installation

You can directly install the `ni.measurements.data.v2.client` package using
`pip` or by listing it as a dependency in your project's `pyproject.toml` file.
